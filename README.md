# Sistema de Mesa de Ayuda

Sistema backend para la gestión de incidentes y solicitudes de soporte técnico.

Permite registrar, asignar y dar seguimiento a incidentes, manejando estados y prioridades, simulando un entorno real de mesa de ayuda.

## Objetivo
Desarrollar una API REST para un sistema de soporte técnico, aplicando buenas prácticas de desarrollo backend con Java y Spring Boot.

## Tecnologías
- Java
- Spring Boot
- Spring Data JPA
- Base de datos relacional
- API REST
